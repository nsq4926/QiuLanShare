# 18 · 应用宝上架（腾讯开放平台）

> 用途：安卓版改投应用宝的操作手册。酷安那一套看 `docs/17`，本文只写差异与本轮准备物。
> 最后更新：2026-11-24。

## 一、一句话

应用宝比酷安多两道**硬门槛**：**软件著作权（强制）** 和 **App 备案（强制）**；
账号个人/企业都能注册，但两者软著都跑不掉。技术上我们的 APK 已经合格（签名、隐私同意、权限收敛都过了），
差的只是资质材料与 4–5 张竖屏截图。

| 项 | 酷安 | 应用宝 |
|---|---|---|
| 开发者账号 | 个人可发 | 个人/企业都可，**软著强制** |
| 软著 | 普通类目可无 | **必须有**（名称与 App 一致） |
| App 备案 | 后台可能要求 | **必填**（备案主体证件号） |
| 截图 | 3–5 张 | **4–5 张**，建议 1080×1920，单张 ≤1 MB |
| 图标 | 512×512 | 512×512 **直角**，**≤200 KB**（最严） |
| 隐私政策 | URL | URL + **正文全文**，必须与 App 内一致 |
| 配套设备 | 备注说明 | 选「是」→ 必须上传**操作视频** |
| 审核时长 | 1–3 天 | 首次 2–5 个工作日 |

## 二、账号（个人 vs 企业）

| 维度 | 个人开发者 | 企业开发者 |
|---|---|---|
| 认证 | 人脸核验 + 本人银行卡小额打款 | 营业执照（手写用途+公章）+ 法人/经办人证件 + 对公打款 + 座机回访 |
| 展示主体 | 个人姓名 | 企业全称 |
| 支持类目 | 工具类没问题；金融/医疗/游戏多数不可 | 全品类 |
| 软著 | 强制 | 强制 |
| 适用 | 本项目首选 | 后续商业化再说 |

个人注册材料：独立 QQ 号（长期使用、无违规）、身份证正反面、手持身份证照片、本人手机号/邮箱、本人银行卡。
入口：<https://open.qq.com> → QQ 登录 → 选择「个人」。

## 三、三张门票

### 3.1 软件著作权（本轮已把材料做完）

- 申请表逐项：`docs/soft-copyright/软著申请信息.md`
- 源程序（60 页，前 30 + 后 30，每页 50 行）：`docs/soft-copyright/秋秋快传-源程序.pdf` / `.docx`
- 说明书（7 页，含 4 张真机截图）：`docs/soft-copyright/秋秋快传-说明书.pdf` / `.docx`
- 生成脚本：`tools/gen_copyright_docs.py`（改代码后重跑即可）
- 登记入口：中国版权保护中心 <https://www.ccopyright.com.cn>；普通登记免费、30–60 工作日；代理加急 3–15 个工作日（几百到上千元）。
- **注意**：软著名称、应用宝展示名、APK 内 `app_name` 必须一致（「软件」后缀可忽略）。

### 3.2 App 备案（工信部）

- 依据：工信部信管〔2023〕105 号。备案要填：主体证件号、App 名称、包名 `com.sanqiu.lanshare`、
  **签名证书 MD5 `a9:82:88:e3:ae:b4:b4:32:f1:97:10:5d:61:18:58:f1`**、SDK 清单（无第三方 SDK）。
- 个人可备案；走云厂商（阿里云/腾讯云）的 App 备案入口，或用服务器接入商。
- 应用宝后台「APP 备案信息 → 应用主体备案证件号」填备案时用的身份证号/统一社会信用代码。
- **实测提醒**：华为设备安装未备案包会弹「应用备案状态未知」，商店审核同样校验。

### 3.3 隐私政策（已备）

- URL：`https://docs.qq.com/doc/DVmdrQUVCck56UEJ0`（所有人可查看）
- 正文：`docs/store/privacy-android.md`（与 App 内「设置 → 关于与隐私」一致）
- 后台要求：URL 点「检测」通过 + 正文全文粘贴一致 + 一张隐私弹窗截图。

## 四、上架流程

1. **注册并认证**（个人：人脸 + 银行卡打款；1 个工作日）。
2. **创建移动应用**：类型选「软件」，填包名 `com.sanqiu.lanshare`（**包名上传后不可改**）。
3. **完善基础信息**：应用名、分类、一句话简介、简介、图标、截图、适配信息、版权证明、APP 备案、隐私政策。
   逐项值见 `docs/store/应用宝上架文案.md`。
4. **版权证明栏**：上传软著扫描件（≤10 张、每张 ≤10 MB）+《应用发布承诺函》（后台下载模板；个人签字/按手印，企业盖章）。
5. **申请上架**：上传 APK（32 位、64 位两个栏位传**同一个** universal APK，本项目无 native 库）、
   填版本特性说明（≤500 字）、选择「涉及登录＝否」「涉及支付＝无支付无提现」、
   「涉及配套设备＝是」并上传操作视频。
6. **提交审核**：首次 2–5 个工作日；驳回原因在「操作 → 查看」里看。
7. **发布**：可选「审核通过后立即发布」或定时发布（新应用定时至少 24 小时后）。

## 六、常见驳回与对策

| 驳回原因 | 对策 |
|---|---|
| 图标超 200 KB 或带圆角 | 用 `app-icon-512.png`（已压到 22 KB，直角） |
| 截图不足 4 张 / 尺寸不符 / 有别的平台水印 | 手机竖屏重截 4–5 张，去掉状态栏里的其他商店图标 |
| 未说明第三方登录方式 | 「涉及登录」选否，登录方式填「无」 |
| 隐私政策正文与 App 内不一致 | 两边用同一份 `privacy-android.md` |
| 备案主体证件号与包名对不上 | 备案时的包名/签名与上架包完全一致 |
| 承诺函选错模板 | 工具类用《应用发布承诺函》；金融/医疗/棋牌有专用表 |
| 审核员单机跑不通 | 「涉及配套设备＝是」+ 上传视频 + 审核备注写自测方式 |

## 九、坑

- **图标 200 KB 是五家里最严的**：512×512 带渐变很容易超；用 `app-icon-512.png`（rgb24，22 KB），别直接传 1024 原图。
- **包名上传后不可改**：`com.sanqiu.lanshare` 已在华为/酷安/应用宝三处统一，别再动。
- **「涉及登录＝是」会强制要测试账号**；我们没有账号体系，必须选否并填「无」，否则会被要求提供账号密码。
- **配套设备栏别选否**：局域网应用选否，审核员单机测不出功能会以「功能无法验证」驳回。
- **截图别带其他商店角标**：OPPO 桌面截图顶部有「工程师开发使用中」横幅，截图前先关掉。
