# LanShare 鸿蒙端 UI 设计规范

> 版本：1.0 · 2026-11-16
>
> 适用范围：`harmony/entry/src/main/ets/` 内全部原生页面、浮层、弹窗、按钮、图标与动画。
>
> 本文件是后续视觉设计与代码评审的唯一规范来源。新增界面先复用令牌与组件，不得另起一套颜色、字号、圆角或动效。

## 一、需求解析

| 字段 | 决策 |
|---|---|
| 项目类型 | 局域网设备消息与文件互传工具 |
| 目标平台 | HarmonyOS 7 / API 26，手机优先，兼容深浅色 |
| 核心任务 | 选择设备、收发消息、收发并保存文件 |
| 品牌调性 | 安静、可靠、轻盈、清晰；工具属性优先于装饰 |
| 参考风格 | 近白冷灰背景、低饱和靛蓝、柔和选中态、细边框、大圆角、弱阴影、充足留白 |
| 硬性约束 | 不改变既有操作逻辑；优先使用系统 Symbol、原生滚动、弹簧、转场和模糊能力 |

### 参考截图风格提炼

1. **配色**：主色只用于发送、选中和关键状态，不大面积铺色；页面底色与卡片有轻微明度差。
2. **字体**：标题短而有力，正文保持常规字重；通过字号、颜色和留白分层，不依赖大量粗体。
3. **间距**：模块之间明显松于模块内部；列表项是独立卡片，不用密集分割线挤满页面。
4. **组件**：卡片和输入框以浅底、细边为主；阴影只表达浮层层级；消息气泡圆角明显。
5. **移动端转译**：保留参考图的视觉语言，但不照搬桌面三栏结构；设备栏继续使用抽屉，聊天仍是主任务。

**配色规则**

- 单屏主色面积原则上不超过 15%；大面积区域使用 `bg/panel/card`。
- 在线状态使用绿色圆点加文字，不只依赖颜色；危险操作必须同时有明确文案。
- 正文与背景对比度至少 4.5:1；大号标题和大图标至少 3:1。
- 禁止在页面内新增未经定义的蓝、绿、红；语义色必须从调色板读取。

### 2.2 字体

统一使用系统默认 `HarmonyOS Sans`，不加载外部字体。

| 层级 | 字号 | 字重 | 建议行高 | 用途 |
|---|---:|---|---:|---|
| 页面主标题 | 20fp | 700 | 26vp | 应用名、全屏页面标题 |
| 会话标题 | 17fp | 600 | 22vp | 当前设备名 |
| 分组标题 | 16fp | 600 | 22vp | 设置分组、弹窗标题 |
| 正文 | 15fp | 400 | 22vp | 消息、设置主文案 |
| 按钮 | 14fp | 500 | 20vp | 主按钮、次按钮 |
| 辅助正文 | 13fp | 400 | 18vp | 设备状态、设置说明 |
| 标注 | 11fp | 400/500 | 16vp | 时间、IP、数量标签 |

- 设备名、文件名最多两行；导航标题和设备列表名称最多一行并省略。
- 不用全大写英文制造层级；数字与 IP 保持默认字体，避免等宽字体造成风格割裂。

### 2.3 间距与尺寸

采用 4vp 基准网格。

| 令牌 | 数值 | 用途 |
|---|---:|---|
| `space1` | 4vp | 图标与短标签、紧密状态 |
| `space2` | 8vp | 标题与副标题、同组元素 |
| `space3` | 12vp | 卡片内部、按钮水平间距 |
| `space4` | 16vp | 页面左右留白、列表项间距 |
| `space5` | 20vp | 卡片舒适内边距 |
| `space6` | 24vp | 设置分组、大模块间距 |
| `space8` | 32vp | 空态与大型区块留白 |

- 手机页面左右安全留白：16vp；消息列表左右：14–16vp。
- 可点击区域最小 44×44vp；主要输入框高度 44–48vp。
- 系统图标常用 20/22fp，应用品牌图标 24fp；不得再用 emoji 充当功能图标。

### 2.4 圆角、边框与阴影

| 令牌 | 数值 | 用途 |
|---|---:|---|
| `radiusSmall` | 8vp | 数量标签、小状态标签 |
| `radiusControl` | 12vp | 输入框、按钮、小图标底板 |
| `radiusCard` | 16vp | 设备项、文件卡片、设置卡片 |
| `radiusBubble` | 20vp | 消息气泡、图片消息 |
| `radiusDialog` | 24vp | 自定义弹窗 |
| `radiusCapsule` | 999vp | 胶囊按钮、状态标签 |

- 普通卡片边框 1vp；分割仅在确有需要时使用 0.5–1vp。
- 卡片默认阴影：半径 10–14vp、Y 偏移 2vp、低透明度；浮层阴影半径 24–32vp。
- 禁止同时使用深边框、重阴影和高饱和底色，三种层级手段最多取两种。

## 三、组件规格卡

### 3.1 按钮

| 类型 | 规格 | 状态与反馈 |
|---|---|---|
| 主按钮 | 高 44–48vp，水平内边距 18–20vp，圆角 12–16vp，主色底白字 | 使用系统 Button `stateEffect`；禁用时浅底弱字，不只降低文字透明度 |
| 次按钮 | 高 44vp，`inputBg` 底，正文色，圆角 12vp | 按压使用系统状态效果；选中时用 `sel` 与主色文字 |
| 图标按钮 | 点击区至少 44×44vp，图标 20–22fp，圆角 12vp 或圆形 | 默认浅底；激活时 `sel/accent`；使用系统 SymbolGlyph |
| 危险按钮 | 保持次按钮形态，文字和图标使用 `danger` | 删除设备仍必须经过系统确认框 |

### 3.2 输入框

- 高 44–48vp，背景 `inputBg`，圆角 12–14vp，字号 14–15fp。
- 光标、焦点和选中内容使用 `accent`；占位使用 `faint`。
- 输入区与发送按钮构成一个整体 Composer，但各按钮仍保留独立点击区域。

### 3.3 卡片与列表

- 设备项：圆角 16vp、垂直内边距 10–12vp、项间距 4–8vp；选中项使用 `sel`，不加粗所有文字。
- 设备头像：40vp 圆形或圆角方形，浅主色底；状态点为独立图形。
- 设置项：按语义组成白色/暗色卡片；主文案 15fp，说明 12–13fp，开关右对齐。
- 空态：系统图标、一句主提示、一句补充说明；不堆放第三个以上操作。

### 3.4 消息气泡

| 类型 | 背景 | 文字 | 圆角与布局 |
|---|---|---|---|
| 接收文字 | `card`，可有 `border` | `text` | 20vp，靠左，最大宽度 78% |
| 发送文字 | `outBg` | `outText` | 20vp，靠右，最大宽度 78% |
| 图片 | 图片本体 | 无额外面板文字 | 18–20vp，保持预览和长按逻辑 |
| 文件 | 与消息方向一致 | 文件名 + 大小 | 图标容器 + 文件信息 + 下载按钮，圆角 16–18vp |

- 时间戳置于气泡外侧，11fp，消息间距至少 8vp。
- 未发送状态使用 `danger` 和「未发送」文字，保留点击查看原因。

### 3.5 导航、抽屉与弹窗

- 顶栏使用 `panel`，通过留白和轻微底边区分层级，不使用厚重导航阴影；顶栏只放应用名/本机信息与设置按钮，不放品牌图标（标题左对齐即可）。
- 会话头的「清空」是 44×44vp 控件，与顶栏设置按钮同尺寸、同右边距（12vp），纵向对齐成一列。
- 设备抽屉宽 280–320vp，**四角 24vp 圆角、四周留 12vp 间隙**（不贴状态栏、不压底部手势条），1vp 边框 + 大阴影自成一个浮层；使用系统模糊遮罩和从左侧滑入转场。
- 改名弹窗宽 86%，最大 420vp，圆角 24vp；包含标题、说明、输入框和等宽双按钮。
- 删除设备、清空聊天继续使用系统 `showAlertDialog`，自动继承 HarmonyOS 7 原生动画和布局。
- 设置页、全屏看图继续作为浮层；返回键只关闭最上层，不改变业务导航语义。

### 3.6 图标与菜单

- 功能图标优先 `sys.symbol.*`：设置、返回、关闭、图片、文件、发送、下载、编辑、删除、复制。
- 图标默认单色，线宽和视觉尺寸一致；只有品牌标识允许渐变。
- 长按菜单使用系统 Menu/MenuItem，保留系统文字选择菜单，不覆盖系统能力。
- 应用图标沿用双向箭头识别符号，底色与本规范同色系（蓝靛，避免偏紫）。**输出 1024×1024 全出血方图、不做圆角**，圆角交给系统遮罩；已选定 A 版渐变 `#4B5FD5 → #7F9CFF`（对角），工程内落 `app_icon.png` 512、`startIcon.png` 192，由 `tools/gen-icons.ps1` 生成；其余候选留在 `design/icon-variants/`。

## 四、页面布局蓝图

### 4.1 主界面

```text
顶栏：品牌标识 + 应用名/本机连接信息                         设置
会话头：设备抽屉 + 当前设备/在线状态                         清空
消息区：接收靠左 / 发送靠右 / 时间与失败状态
输入区：图片 + 文件 + 消息输入 + 发送
```

- 主页面始终以聊天为中心，不新增 Tab，不改变原有设备选择路径。
- 未选择设备时显示品牌空态；选择设备后消息区与输入区原位替换。

### 4.2 设备抽屉

```text
设备与会话 + 数量                                      关闭
设备卡片列表：状态点 + 名称/预览/IP + 未读 + 改名/删除（不使用头像）
手动添加：IP 或 IP:端口 输入框 + 添加
```

- 状态点 7vp，紧贴设备名前，替代原头像上的角标；未读角标移到操作按钮左侧，不再叠在头像上。

### 4.3 设置页

```text
返回 + 设置 + 页面说明
接收卡片：自动接收开关
外观卡片：跟随系统 / 亮色 / 暗色
聊天记录卡片：不清理 / 7 天 / 30 天 / 90 天 / 退出清理
收到的文件卡片：图片自动保存 / 文件自动保存
底部说明
```

### 4.4 全屏看图

- 黑色沉浸式背景；顶部毛玻璃工具条包含关闭、索引和保存。
- 中部 Swiper 保留系统滑动、边缘回弹、双指缩放与拖拽；不添加额外页签或新手势。

## 五、动效与系统特效

| 场景 | 系统能力 | 参数基准 |
|---|---|---|
| 抽屉、设置页、看图、改名弹窗出现/消失 | `TransitionEffect` + 系统曲线 | 240–320ms；位移结合透明度，弹窗结合轻微缩放 |
| 设备选中、主题选项、发送按钮可用态 | 属性动画 | 160–220ms，`FastOutSlowIn` 或 `EaseOut` |
| 浮层关闭、缩放复位 | `UIContext.animateTo` + 系统弹簧曲线 | 自然回弹，不连续弹跳 |
| 消息与设备列表滚动 | 系统 List/Scroll `EdgeEffect.Spring` | 保留系统回弹，不自定义滚动物理 |
| 抽屉与模态层级 | 系统 `backdropBlur/backgroundBlurStyle` | 只用于浮层，避免全屏多层实时模糊 |
| 按钮按压 | Button `stateEffect` / 系统状态效果 | 不额外添加闪烁、粒子和循环动画 |

**动效原则**

1. 动效只解释层级、状态和因果，不为装饰拖慢操作。
2. 普通反馈不超过 220ms，页面级转场不超过 320ms；弹簧动画由系统决定自然时长。
3. 不使用无限循环呼吸、旋转或光斑；不阻塞发送、选择和滚动。
4. 位置/尺寸频繁变化优先改用透明度、缩放和系统转场，避免低端设备掉帧。

## 六、前端实现指引

- 颜色唯一来源：`common/Settings.ets` 中 `LsPalette` 与 `paletteOf()`。
- 应用级主题：切换设置时必须调用 `ApplicationContext.setColorMode()`，让系统确认框、菜单、Toast 与原生控件跟随亮/暗主题；只切页面调色板会出现“暗色页面 + 亮色系统弹窗”。
- 尺寸与时长唯一来源：`common/UiTokens.ets`；组件中不得散落新令牌。
- 页面实现：`pages/Index.ets`；新增可复用结构使用带 `Ls` 业务前缀的 Builder 或组件，避免顶层声明重名。
- 所有 ForEach key 必须包含会变化的展示字段；看图列表继续保留下标以避免同路径撞键。
- 图标必须先在项目 ArkUI API 资源表中确认系统符号名，禁止猜测。
- 动画通过 `this.getUIContext().animateTo()` 或组件转场实现，禁止调用已废弃的全局 `animateTo`。
- 所有 8 位色值必须按鸿蒙的 `#AARRGGBB` 书写，例如 12% 白为 `#1FFFFFFF`；按 Web 的 `#RRGGBBAA` 书写会变成不透明错误颜色。
- 聊天区使用 `layoutWeight(1)` 占剩余高度；禁止恢复 `height('100%')` 叠加顶栏的溢出写法。
- 键盘避让继续使用 `KeyboardAvoidMode.RESIZE`；打开设置前继续收起键盘。
- 模糊只覆盖抽屉、遮罩和顶部看图工具条；消息列表不做逐气泡实时模糊。

## 七、校验清单

每次 UI 变更必须逐项确认：

- [ ] 所有页面、浮层、按钮均只使用本文件定义的颜色、字号、间距和圆角。
- [ ] 亮色、暗色、跟随系统三种模式均无状态栏文字消失或低对比问题。
- [ ] 所有功能图标为系统 Symbol 或规范资源，无 emoji 功能图标。
- [ ] 所有关键点击区至少 44×44vp，长设备名、长文件名不挤压主要按钮。
- [ ] 抽屉、改名、设置、看图、系统确认框和长按菜单均有正确打开、关闭与返回行为。
- [ ] 消息收发、文件收发、图片选择、保存、拖拽、改名、删除、清空等逻辑未改变。
- [ ] 输入栏不被裁切，键盘弹起时顶栏保持可见，设置页不露出底层输入栏。
- [ ] `tools\arkts.ps1`、JSON 引号检查、协议一致性检查和构建全部通过。
- [ ] 按 `docs/12-工具调用指南.md` 在真机运行并截图检查主页面、抽屉、设置、弹窗和看图。
- [ ] 不以「静态检查通过」替代真机渲染和主要交互验证。
