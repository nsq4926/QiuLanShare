## 二、现在能做什么（一句话版）

- **设备发现**：同 Wi-Fi 自动出现；可关"主动发现"（不找别人）或"被发现"（别人找不到我）；
  抽屉下拉/「立即搜索」立刻找一次；手动填 IP 兜底。
- **聊天**：文字、图片、文件双向；失败标「未发送」可重发；清空只清本端记录。

- **设置**：发现与接收、主题三态、聊天记录保留期、收到文件自动存相册/下载。

## 四、手动验证（给用户，10 分钟）

1. **Windows**：部署后重启 TM → 任务栏出现 `IP` 与 `互通` → 浏览器开 `http://<ip>:8765/`。
2. **鸿蒙**：桌面点图标 → 顶栏 `设备名 · IP:8765` → 抽屉能看到电脑与两台安卓 → 发一张图/一个文件。
3. **Android**：桌面点图标（服务在设置里可开关）→ 抽屉下拉 → 收到文件后去相册/下载找。
4. **通知**：把手机切后台 → 从电脑发一条消息 → 通知栏应出现 → 点通知应落到该会话。
5. **续传**：传一个大文件（>10 MB）→ 抽屉里出现两行以上进度 → 通知栏同步显示百分比。

## 五、工程约定（改代码前必看）

1. **判据冲突时只能改判据，不能改被测行为**（不得为让某条变绿而取消网卡过滤）。
2. **同一判据在两处实现必须同源**（脚本按名字判、产品按 `IfType` 判 = 假绿灯来源）。
3. **能连上 ≠ 连的是我们对端**（端口可能被别的程序占，必须核对 `deviceId`）。
4. **权威源只能有一个**：常量/枚举/字段名只从 `01` 与各自 `Proto` 抄。
5. **文件目录键与会话键必须同源**（否则"消息进 A 会话、附件落 B 目录"）。
6. **`msgId` 由服务端分配**；客户端只能沿用已存在的 `msgId` 表示重发。
7. **"清空"只清记录不删文件**；只有"删除设备"才清目录，且必须先 `dry=1`。
8. **内容相同的文件只留一份**（尺寸 + 64 位哈希），同名不同内容才加 `(2)`。
9. **失败要响亮**：静默失败是本项目最主要的 bug 形态，`catch` 不许空着。
10. **ArkUI `ForEach` 的 key 必须带上所有会变的展示字段**（只放 ID → 界面静默不更新）；
    可能撞键的地方（同图收两次）还要带下标。
11. **Compose 读外部可变对象要整取快照**（只递增 tick 不会重跑读值分支）。
12. **移动端改动必须装真机**：静态检查全绿也可能跑不起来。

## 六、环境坑速查（都踩过，别删）

| 坑 | 症状 | 真因 / 处置 |
|---|---|---|
| `build.bat` 中文注释 | 每次构建两条"不是内部或外部命令" | cmd 按 GBK 读 .bat → 保持纯 ASCII |
| `rc.exe` 不跟踪 RCDATA | 改了 `index.html` 但 DLL 里是旧页面 | `build.bat` 无条件 touch `web.rc` |
| 网页读哪一份 | 改了没生效 | 优先读 `<模块目录>\web\index.html`；浏览器加 `?v=` |
| `.ps1` 编码 | 解析失败 / 中文乱码 | 必须 UTF-8 with BOM 或纯 ASCII |
| 控制台 GBK | 中文「无」被吃掉显示成 `FAIL` | 只看汇总行数字 |
| `curl` 走代理 | 127.0.0.1 报 `upstream connect failed` | 加 `--noproxy '*'` |
| `curl` 打 `dl.google.com` | `CRYPT_E_REVOCATION_OFFLINE` | 假失败，加 `--ssl-no-revoke` |
| `HTTP_PROXY` 指向本地代理 | 下载/SDK/Gradle 全卡死 | 构建脚本内清空代理变量 |
| 本机 WMI 坏 | `Get-NetIPAddress` 抛"无效类" | 改用 `[System.Net.NetworkInformation.*]` |
| 端口递进前提 | 递进永不触发 | TCP 必须 `SO_EXCLUSIVEADDRUSE`；UDP 相反用 `SO_REUSEADDR` |
| 部署 DLL 被占用 | `Device or resource busy` | 先停 TrafficMonitor |
| `cmd /c` 在 Agent 工具里被拦 | 命令直接被拒 | 用 PowerShell 工具或直接调用 exe |
| `devecocli` 代理 | `Invalid proxy authorization` | `tools\devecocli-noproxy.ps1` |
| 华为 p12 打不开 | 报"口令错" | 格式非标不是口令错；hvigor 能解 |
| `aa start` 报锁屏 | `The device screen is locked` | `hdc shell power-shell wakeup` |
| `bm install` | `install file path invalid` | 改用 `hdc install -r <本地 hap>` |
| hdc 在 Git Bash | 路径被转换 / 截图失败 | `MSYS_NO_PATHCONV=1`；截图后缀 `.jpeg`；`file recv` 用相对路径 |
| 图库保存弹窗一闪就关 | 传 `'file://' + path` | 必须 `fileUri.getUriFromPath(path)` |
| `getUserDownloadDir()` 抛 801 | 手机上通不了 | 该 API 只在 2in1/PC 有 → 退 `DocumentViewPicker.save()` |
| 8 位色值写成 `#RRGGBBAA` | 半透明白变亮黄 | 鸿蒙按 `#AARRGGBB` 解析 |
| 只换页面调色盘 | 系统弹窗仍是亮色 | 还要 `getApplicationContext().setColorMode(...)` |
| `MenuItem` 放系统 Symbol | 菜单图标空白 | 要用 `symbolStartIcon: new SymbolGlyphModifier(...)` |
| `Column{ 顶栏; 内容.height('100%') }` | 输入栏跑出屏幕 | 子区一律 `layoutWeight(1)`；键盘避让 `RESIZE` |
| AS 自带 JBR 25 | Gradle 8.x 起不来 | 用 JDK 21（`D:\APP\AndroidToolchain`） |
| OPPO 装 apk | `Failure [-99]` | 系统安装器秒关自己 → session API（脚本已回退） |
| Compose 读外部可变对象 | "服务在跑、界面说没跑" | 每秒整取快照赋给 `mutableStateOf` |
| `screencap` 与点击坐标不一致 | 点不中按钮 | 截图可能被缩放，**点击坐标 = 截图坐标 × 缩放比**（MatePad ×2.37） |
| `hilog` 查不到应用日志 | grep 为空 | 用 `hdc shell "hilog -x"` 先看全量，再按 TAG `LanShare` 过滤 |
| 鸿蒙长同步 IO | 进程被杀、hilog 只有 `THREAD_BLOCK_6S`/`appfreeze` | HTTP 与 UI 同线程：>6 s 同步循环就被 FreezeDetector 杀 → 分片 + `await yieldToUi()`，大文件跳过去重哈希 |

**环境/教训（新增，长期有效）**
- **鸿蒙真机没有录屏**：`hdc shell screenrecord` → `inaccessible or not found`；`uitest screenCap` 只能单张。要视频只能连拍 `snapshot_display`（实测 ~2.2 fps，1320×2232 JPEG 约 120 KB/帧），并用 `date +%s%N` 给每帧打设备时钟，否则按固定帧率编码会让进度条变速。
- **`uinput -K -t` 只吃 ASCII**：中文直接报 `The character of index 0 is invalid`；中文文本必须用 `uitest uiInput text '<文本>'`（输入法注入）。反过来，**平滑多指触摸只有 `uinput -T -m`** 能做（双指捏合靠它）。
- **逐字删除只删光标左侧**：清输入框必须先点输入框**右端**把光标落到末尾，再连按 `KEYCODE_DEL(2055)`，否则残留会和下一轮输入拼成半截串（本轮第一版录像就是这么废掉的）。
- **聊天页按 Back 是退出应用**，不是回列表；回列表要点左上角那个按钮（聊天页 `[36,333]-[168,465]`）。
- **看图页在最后一张向左滑 = 关闭看图**（不是翻页）；要从最后一张翻到上一张就向右滑。
- **自动存相册/自动保存开着时，每收一张都会弹一次系统确认框**（权限不会记住）；录演示前先关掉，改成在看图页点「保存」只弹一次。
- **MSYS 下跑 .bat 要写 `cmd /c "..."`**：`cmd //c` 会被路径转换吃掉参数，表现是只打印 cmd 横幅、什么都没执行。

**环境/教训（新增，长期有效）**
- **沙箱里两端构建都会被挡**：hvigor 要在 `~/.hvigor/project_caches/...` 里建**符号链接**装自身依赖（沙箱报 `EPERM: symlink`），gradle 要写 `~/.gradle/native`（报 `Failed to load native library 'native-platform.dll'`）。绕法：gradle 用 `GRADLE_USER_HOME=<仓库>/.work/gh`（把 `~/.gradle` 整份拷进去）+ `--offline`；hvigor 没有等价绕法（它会自己重建链接），只能 `danger-full-access` 跑 `tools\build-hap.bat`。
- **鸿蒙分享技能必须写 `utd`，不能写 `type`**：`module.json5` 的 `uris[].type` 在 `bm dump` 里原样保留、`utd` 为空 → 面板永远匹配不上。必须 `{"scheme":"file","utd":"general.image","maxFileSupported":15}`；`maxFileSupported: 0` 等于一个文件都不收。
- **鸿蒙面板不列 debug 签名包**：注册字段与 WorkBuddy 完全一致仍不出现；判断与分发渠道/签名信任有关，release 包不能侧载（9568322），只能等 AGC 上架后复验。
- **`am start --eu` 才是 Parcelable Uri**：`--es` 会把 URI 塞成 String，`getParcelableExtra<Uri>` 读到 null（分享进来会被静默忽略，看起来像「什么都没发生」）；API 23 的 `am` 没有 `-g`，授读权限用 `-f 1`（`FLAG_GRANT_READ_URI_PERMISSION`）。
- **长按怎么自动化**：鸿蒙 `uitest uiInput longClick x y` 能触发 ArkUI 的 `bindContextMenu`；安卓 Compose 用 `adb shell input swipe x y x y 1300`（同点长按）。
- **分享的 URI 权限是「一次、随应用存活」**：两端都直接把发送方给的 URI 流式读出去（不复制副本），所以发送必须在应用活着的时候完成；应用被杀这次分享就作废（已写进 `13` 已知限制）。

**环境/教训（新增，长期有效）**
- **`assembleRelease` 离线会挂在 `lintVitalRelease`**：它要下 `com.android.tools.lint:lint-gradle:31.13.2`，离线报 `No cached version`；联网跑一次即可，纯离线发版加 `-x lintVitalRelease`。

- **腾讯文档默认可能是"所有人可编辑"**：隐私政策必须改成"所有人可查看"，否则任何人能改政策正文。
- **`fill` 进腾讯文档会把换行吃掉**（1073 字挤成一段）；要保留段落必须走系统剪贴板 + `Ctrl+V`（`Set-Clipboard` + bsk `press Control+v`）。
- **Gradle 构建仍需 `GRADLE_USER_HOME=<仓库>/.work/gh`**（沙箱不能写 `~/.gradle`），且 `JAVA_HOME` 要给 **Windows 路径**（`D:/...`），MSYS 的 `/d/...` 会让 `gradle.bat` 报 invalid directory。
