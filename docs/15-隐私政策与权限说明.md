# 15 · 隐私政策与权限说明（上架用）

> 用途：AppGallery 应用信息里的「隐私政策」正文与 URL、审核备注模板、权限说明。
> 本文件是**对外文案**，写的是应用真实行为；改代码里任何采集/存储行为时要同步改这里。
> 最后更新：2026-11-22（定名「秋秋快传 / QiuLanShare」）。

## 一、一句话结论

**秋秋快传不联网、不注册、不采集任何个人信息**：所有消息、图片、文件只在你和同一局域网内的另一台设备之间点对点传输，
不经过任何服务器，应用本身没有云端账号体系，也没有埋点、广告或统计 SDK。

## 二、隐私政策正文（可直接粘到 AGC，或托管成网页后填 URL）

```text
秋秋快传（QiuLanShare）隐私政策
更新日期：2026年11月22日
生效日期：2026年11月22日

一、我们收集哪些信息
秋秋快传是一款纯局域网的点对点文件与消息传输工具。我们不收集、不上传、不存储您的任何个人信息，
包括但不限于：姓名、手机号、通讯录、位置、设备标识符（IMEI/OAID/IDFA）、剪贴板、应用列表、使用行为与日志。
应用没有账号注册与登录，没有云端服务器，没有广告或统计分析 SDK。

二、数据如何传输
1. 应用通过 UDP 广播在同一局域网内发现其他安装了本应用的设备，广播内容仅包含：设备名称、
   应用生成的随机设备标识、局域网 IP 与端口号，用于让对端认出您并建立连接。
2. 您发送的文字、图片与文件，通过 HTTP 直接在您的设备与对端设备之间传输（默认端口 8765），
   不经过任何中转服务器，也不会被上传到互联网。
3. 传输只在您主动点击「发送」时发生；关闭「被发现」后，本机不再广播、也不再回应其他设备的发现请求。

三、数据存储在哪里
1. 接收与发送的聊天记录、图片与文件副本，保存在应用自身的沙箱目录内，仅本应用可访问。
2. 您可以在「设置」中选择是否把收到的图片自动存入系统相册、把收到的文件保存到系统下载目录；
   这些操作由系统保存框完成，文件保存在您指定的位置。
3. 您可以在「设置」中设置聊天记录保留期限（不清理 / 7 天 / 30 天 / 90 天 / 退出时清理），
   也可以随时在会话页清空本机记录。卸载应用会删除应用沙箱内的全部数据。

四、权限及用途
1. 网络权限（INTERNET）：在局域网内收发消息与文件。
2. 获取网络信息权限（GET_NETWORK_INFO）：读取本机局域网 IP 与网络状态，用于建立连接与显示本机地址。
3. 后台运行权限（KEEP_BACKGROUND_RUNNING）：应用切到后台后继续完成正在进行的传输，避免大文件中途中断。
应用不申请通讯录、位置、相机、麦克风、剪贴板等权限。

五、第三方共享
我们不与任何第三方共享您的信息，因为应用不采集信息，也不接入第三方 SDK。

六、未成年人保护
本应用不采集任何个人信息，未成年人可在监护人指导下使用。

七、政策更新
如本政策发生变更，我们会在应用新版本发布时同步更新本页面。

八、联系我们
开发者：聂思奇
联系邮箱：（请填写您对外公开的邮箱）
```

## 三、权限清单（与 module.json5 逐条对应）

| 权限 | 声明位置 | 用途（对审核的口径） |
|---|---|---|
| `ohos.permission.INTERNET` | `entry/src/main/module.json5` | 局域网内 HTTP 收发消息与文件（端口 8765~8767） |
| `ohos.permission.GET_NETWORK_INFO` | 同上 | 取本机局域网 IPv4、判断 Wi-Fi 是否可用，用于设备发现与地址显示 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | 同上 | `backgroundModes: ["dataTransfer"]`，后台继续传输大文件 |

> 应用**不申请**：位置、通讯录、相机、麦克风、剪贴板、读取应用列表、设备标识符。
> 图片写入相册、文件写入下载目录走系统保存框/媒体库，不需要额外存储权限。

## 六、安卓版（酷安）差异（2026-11-22 补充）

### 6.1 托管地址

安卓版与鸿蒙版共用同一份政策，托管在腾讯文档，权限设为**所有人可查看**（不能是"所有人可编辑"）：

```
https://docs.qq.com/doc/DVmdrQUVCck56UEJ0
```

代码里只有一处引用：`android/app/src/main/java/com/sanqiu/lanshare/core/AppLinks.kt` 的 `PRIVACY_URL`。
换托管地址改这里即可，隐私同意页与「关于与隐私」页会同时生效。

### 6.2 安卓权限清单（与 `AndroidManifest.xml` 逐条对应）

| 权限 | 用途（对审核的口径） |
|---|---|
| `INTERNET` | 局域网内收发消息与文件（端口 8765 起） |
| `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | 读取本机局域网 IP、判断 Wi-Fi 是否可用 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_DATA_SYNC` | 切到后台后继续传输大文件 |
| `POST_NOTIFICATIONS` | 新消息与传输进度提醒，可拒绝、可随时关闭 |
| `WRITE_EXTERNAL_STORAGE`（`maxSdkVersion=28`） | 仅 Android 9 及以下把用户主动保存的图片/文件写入相册或下载目录 |

**已移除** `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`：改为「设置 → 发现与接收 → 后台保活」跳系统电池优化页，
由用户手动放行。权限清单里不再有"可绕过系统省电策略"这一项，审核口径更干净。

`usesCleartextTraffic="true"` 保留（局域网没有可签发证书的域名），理由写在
`res/xml/network_security_config.xml` 的注释里，审核备注也需同步说明。

### 6.3 与鸿蒙文案的差异

- 权限名从 `ohos.permission.*` 换成 Android 的 `INTERNET` / `ACCESS_NETWORK_STATE` 等；
- 多一条 `POST_NOTIFICATIONS`（Android 13+ 运行时权限）；
- 存储权限只在 Android 9 及以下声明；
- 后台保活不再申请权限，改为用户手动放行。

正文见 `docs/store/privacy-android.md`（与腾讯文档同步的源文本），上架操作见 `docs/17-安卓上架.md`。
