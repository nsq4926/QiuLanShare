## 一、脚本清单（`tools\`）

### 1.1 构建与部署

| 脚本 | 用法 | 说明 |

### 1.2 断言与静态检查

| 脚本 | 用法 | 覆盖 |
|---|---|---|
| `test-multinode.ps1` | `-Stage readonly\|transitions [-NegativeControl]` | 协议/五态/端口递进/双实例；参数 `-Base -PeerIp -Port -Instance -Dll -Exe -TimeoutSec` |
| `test-files.ps1` | `[-NegativeControl]` | F1–F6：落盘、分目录、同名不覆盖、内容去重、清空不删文件；独立 dataDir + 端口 |
| `check-protocol-parity.py` | 直接跑 | Windows ↔ 鸿蒙 7 组字段逐字对齐（含设备表落盘） |
| `check-json-quotes.py` | 直接跑 | 鸿蒙 `.ets` 里 JSON 引号是否写重（症状：对端静默丢弃） |
| `verify-doc.py` | 直接跑 | 文档自检总入口（路径 + 命令） |
| `verify-doc-paths.py` | 直接跑 | 本文引用的本地路径是否存在 |
| `verify-doc-cmds.py` | 直接跑 | 本文写的 `devecocli` 子命令是否真实存在 |

**断言输出只有四种**：`[PASS]` / `[FAIL]` / `[UNCOVERED]`（样本造不出来） / `[SELFCHECK]`。
`UNCOVERED` 与 `PASS` **严格区分**，不许混算。

**负控制是硬规矩**：新写或修好的断言，先用必然失败的数据跑一次证明它能红，再用真实数据跑。

## 二、日常流程

**改 Windows 代码**

```powershell
windows\build.bat x64 Release
tools\deploy-windows.bat "C:\Tools box\System Tools\TrafficMonitor"   # 会等 TM 退出
curl.exe -s --noproxy "*" http://127.0.0.1:8765/api/ping
```

**只改网页**：`copy /Y windows\web\index.html "<TM>\plugins\web\index.html"`，
浏览器带 `?v=随机` 强刷（服务端优先读磁盘那份）。

**改鸿蒙**：`tools\arkts.ps1` → `deveco.ps1 build` → `deveco.ps1 run -Device <serial>` →
真机看 UI + `deveco.ps1 log`。**必须装真机**，静态检查全绿也可能跑不起来。

**改 Android**：`tools\android-build.ps1 test` → `build` → `android-device.ps1 -Action install`
→ 截图核对。设备坐标见 §四。

**发版前**（全绿才提交）：
`check-json-quotes.py` → `check-protocol-parity.py` → `arkts.ps1` → `android-build.ps1 test` →
`windows\build.bat x64 Release` → `verify-doc.py`。

## 四、设备与调试

| 操作 | 命令 |
|---|---|
| 鸿蒙设备列表 | `hdc list targets`（`IP:port` 也算在线） |
| 鸿蒙唤醒 | `hdc shell power-shell wakeup` |
| 鸿蒙截图 | `hdc shell snapshot_display -f /data/local/tmp/s.jpeg` → `hdc file recv /data/local/tmp/s.jpeg s.jpeg` |
| 鸿蒙日志 | `hdc shell "hilog -x \| grep -i lanshare"`（DOMAIN `0x9527`） |
| 安卓设备 | `adb devices -l` / `tools\android-device.ps1 -Action info` |
| 安卓启动（自动化） | `adb shell am start -n com.sanqiu.lanshare/.MainActivity --ez autostart true` |
| 安卓截图 | `adb exec-out screencap -p > shot.png` |
| 安卓日志 | `adb logcat -d -t 300 \| grep -iE "AndroidRuntime\|sanqiu"` |
| 安卓坐标换算 | `wm size` 是物理分辨率；`screencap` 可能被缩放 → **点击坐标 = 截图坐标 × 缩放比** |

> Git Bash 下 `hdc` 必须 `export MSYS_NO_PATHCONV=1`；`hdc file recv` 的本地路径写**相对路径**。
> 鸿蒙通知跳转模拟：`aa start -a EntryAbility -b <bundle> --ps deviceId <id>`。
> 安卓通知跳转模拟：`am start -n <pkg>/.MainActivity -f 0x20000000 --es deviceId <id>`（必须 SINGLE_TOP）。

## 五、踩坑速查（工具相关）

| 坑 | 真相 |
|---|---|
| 控制台中文显示成 `FAIL` / 乱码 | PS 5.1 按 GBK 读；只看汇总行数字，脚本文件必须 UTF-8 with BOM 或纯 ASCII |
| `.ps1` 解析失败 | 无 BOM 的 UTF-8 被按 ANSI 解码 → 保存为 UTF-8 with BOM |
| MSBuild `MSB6001` | `HTTPS_PROXY` 与 `https_proxy` 同时存在 → 构建脚本先清空 |
| `curl` 打 127.0.0.1 失败 | 本机有 `HTTP_PROXY` → 加 `--noproxy "*"` |
| `curl` 打 `dl.google.com` 报吊销离线 | 加 `--ssl-no-revoke`（不是墙） |
| `python` 报 "Python was not found" | PATH 里是商店壳；本机真实 python 可用 `python -V` 确认 |
| `devecocli` 报 `Invalid proxy authorization` | 先跑 `tools\devecocli-noproxy.ps1` |
| `aa start` 报锁屏 | 先 `hdc shell power-shell wakeup` |
| `bm install` 报 `install file path invalid` | 改用 `hdc install -r <本地 hap>` |
| 鸿蒙截图失败 | 后缀必须 `.jpeg`；Git Bash 要 `MSYS_NO_PATHCONV=1` |
| OPPO `adb install` 报 `-99` | 系统安装器秒关自己 → 用 session API（脚本已自动回退） |
| `Start-Process` 报"字典中的关键字" | 本机代理变量冲突；脚本内启动进程而非命令行 |
| `cmd /c` 在 Agent 工具里被拦 | 改用 PowerShell 工具或直接调用 exe |

## 六、断言设计约定（写新断言前必读）

1. **不写死契约**：字段名/枚举/TTL 从实际响应读，脚本只硬编码"断言逻辑"。
2. **每条断言必须能红**：先跑负控制，再跑真实数据。
3. **同一判据只能有一处实现**：脚本按名字判、产品按 `IfType` 判 = 假绿灯。
4. **"能连上" ≠ "连的是我们对端"**：必须核对 `deviceId`。
5. **写操作必须用独立 `TMLS_DATA_DIR` + 独立端口**，绝不碰真实保存目录。
6. **文档与断言解耦**：断言 ID 与任务文档逐字一致，不另做映射表。
