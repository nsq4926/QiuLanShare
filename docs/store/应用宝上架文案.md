## 二、应用简介（60–500 字，可直接粘）

```
秋秋快传是一款纯局域网的点对点传输工具：不注册、不登录、没有云端服务器，文字、图片和文件只在你的设备与同一 Wi-Fi 下的另一台设备之间直接传输。

所有内容都不经过任何中转：没有账号体系，没有广告，没有统计 SDK，应用内也没有任何第三方 SDK。断开 Wi-Fi 它什么也做不了——这是设计，不是缺陷。

主要功能：
· 同一 Wi-Fi 下自动发现设备，也可手动填 IP 添加
· 文字、图片、文件双向发送，支持多选与系统分享
· 单文件最大 4 GB，1 MB 分片 + 断点续传
· 通知栏实时显示传输速度与百分比
· 全屏看图：双指缩放、双击放大、左右翻页、保存相册
· 深色模式、聊天记录保留期限、后台传输保活

跨端：Windows 端（TrafficMonitor 插件）、鸿蒙端与安卓端使用同一套协议，三端可以互传。

隐私：不收集姓名、手机号、位置、通讯录、剪贴板、设备标识；只申请网络、网络状态、前台服务与通知权限。图片/文件保存走系统保存框。
隐私政策：https://docs.qq.com/doc/DVmdrQUVCck56UEJ0
```

## 六、涉及配套设备（关键栏位）

本应用需要两台设备在同一 Wi-Fi 才能演示完整功能，后台「涉及配套设备」选 **是**，并上传**配套设备操作视频**：

- 现成素材：`docs/demo/QiuLanShare-demo-1.0.0.mp4`（3 分 25 秒，7.7 MB，含设备发现/文字/收发文件/看图/设置/通知 8 章）。
  该视频录制于鸿蒙端，界面与本应用同源同设计；若审核要求"须与提交版本一致"，用安卓手机按同样章节重录一遍（10 分钟内可完成）。
- 视频里要能看清：两台设备在同一 Wi-Fi、互相发现、发送一条文字、发送一个文件并出现进度条。

**审核备注**（粘到「审核说明/备注」）：

```
本应用是纯局域网的点对点传输工具，无账号、无服务器，需要两台设备接入同一 Wi-Fi 才能看到完整功能。

自测方式（二选一）：
A. 两台设备：设备 A 安装本应用，设备 B 安装同一版本（安卓或 Windows 端），连同一 Wi-Fi，打开后自动发现对方；不出现时在「设备列表 → 手动添加」填对方 IP 与端口 8765。
B. 单台设备：打开「设置 → 关于与隐私 → 没有第二台设备？」，页面显示本机地址与自测三步。

权限说明：仅使用网络、网络状态、前台服务与通知权限，全部用于局域网收发与后台传输；不采集个人信息，不申请位置、通讯录、相机、麦克风。
隐私政策：https://docs.qq.com/doc/DVmdrQUVCck56UEJ0
```
