## 一、应用简介

秋秋快传（QiuLanShare）是一款纯局域网的点对点文件与消息传输工具。它没有账号体系、没有云端服务器，也不提供任何互联网内容服务：文字、图片和文件只在您与同一 Wi-Fi 内的另一台设备之间直接传输，不经过任何中转服务器。

## 二、我们收集哪些信息

我们不收集、不上传、不存储您的任何个人信息，包括但不限于：姓名、手机号、通讯录、位置、相机、麦克风、剪贴板、应用列表、设备标识符（IMEI / OAID / IDFA / Android ID）、使用行为与日志。

应用没有注册与登录，没有广告 SDK、统计 SDK 或任何第三方 SDK。

## 三、权限及用途

1. 网络（INTERNET）：在局域网内收发消息与文件，默认端口 8765。
2. 网络状态（ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE）：读取本机局域网 IP 与网络状态，用于建立连接、显示本机地址。
3. 前台服务（FOREGROUND_SERVICE、FOREGROUND_SERVICE_DATA_SYNC）：应用切到后台后继续完成正在进行的传输，避免大文件中途中断。
4. 通知（POST_NOTIFICATIONS）：新消息与传输进度提醒；您可以在系统设置中随时关闭。
5. 存储（WRITE_EXTERNAL_STORAGE，仅 Android 9 及以下）：把您主动保存的图片或文件写入系统相册、下载目录。

应用不申请位置、通讯录、相机、麦克风、读取应用列表等权限。

## 四、数据如何传输

1. 应用通过 UDP 广播在同一局域网内发现其他安装了本应用的设备，广播内容仅包含：设备名称、应用生成的随机设备标识、局域网 IP 与端口号。
2. 您发送的文字、图片与文件通过 HTTP 直接在您的设备与对端设备之间传输，不经过任何中转服务器，也不会上传到互联网。
3. 传输只在您主动点击「发送」时发生；关闭「被发现」后，本机不再广播，也不再回应其他设备的发现请求。

## 五、数据存储在哪里

1. 聊天记录、图片与文件副本保存在应用自身的沙盒目录内，仅本应用可访问。
2. 您可以在「设置」中选择是否把收到的图片自动存入系统相册、把收到的文件保存到系统下载目录；这些操作由系统保存框完成，文件保存在您指定的位置。
3. 您可以在「设置 → 聊天记录」中设置保留期限（不清理 / 7 天 / 30 天 / 90 天 / 退出时清理），也可以随时在会话页清空本机记录。卸载应用会删除应用沙盒内的全部数据。

## 六、第三方共享

我们不与任何第三方共享您的信息，因为应用不采集信息，也不接入第三方 SDK。

## 七、未成年人保护

本应用不采集任何个人信息，未成年人可在监护人指导下使用。

## 八、您的权利

您可以随时清空单个会话或全部记录、修改记录保留期限、关闭「被发现」、在系统设置中关闭通知，或直接卸载应用删除全部本地数据。

## 九、政策更新

如本政策发生变更，我们会在新版本发布时同步更新本页面，并更新页面顶部的更新日期。
