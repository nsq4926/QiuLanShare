秋秋快传（QiuLanShare）隐私政策

更新日期：2026年11月22日

生效日期：2026年11月22日

一、我们收集哪些信息

秋秋快传是一款纯局域网的点对点文件与消息传输工具。我们不收集、不上传、不存储您的任何个人信息，

包括但不限于：姓名、手机号、通讯录、位置、设备标识符（IMEI/OAID/IDFA）、剪贴板、应用列表、使用行为与日志。

应用没有账号注册与登录，没有云端服务器，没有广告或统计分析 SDK。

二、数据如何传输

1. 应用通过 UDP 广播在同一局域网内发现其他安装了本应用的设备，广播内容仅包含：设备名称、

应用生成的随机设备标识、局域网 IP 与端口号，用于让对端认出您并建立连接。

2. 您发送的文字、图片与文件，通过 HTTP 直接在您的设备与对端设备之间传输（默认端口 8765），

不经过任何中转服务器，也不会被上传到互联网。

3. 传输只在您主动点击「发送」时发生；关闭「被发现」后，本机不再广播、也不再回应其他设备的发现请求。

三、数据存储在哪里

1. 接收与发送的聊天记录、图片与文件副本，保存在应用自身的沙箱目录内，仅本应用可访问。

2. 您可以在「设置」中选择是否把收到的图片自动存入系统相册、把收到的文件保存到系统下载目录；

这些操作由系统保存框完成，文件保存在您指定的位置。

3. 您可以在「设置」中设置聊天记录保留期限（不清理 / 7 天 / 30 天 / 90 天 / 退出时清理），

也可以随时在会话页清空本机记录。卸载应用会删除应用沙箱内的全部数据。

四、权限及用途

1. 网络权限（INTERNET）：在局域网内收发消息与文件。

2. 获取网络信息权限（GET_NETWORK_INFO）：读取本机局域网 IP 与网络状态，用于建立连接与显示本机地址。

3. 后台运行权限（KEEP_BACKGROUND_RUNNING）：应用切到后台后继续完成正在进行的传输，避免大文件中途中断。

应用不申请通讯录、位置、相机、麦克风、剪贴板等权限。

五、第三方共享

我们不与任何第三方共享您的信息，因为应用不采集信息，也不接入第三方 SDK。

六、未成年人保护

本应用不采集任何个人信息，未成年人可在监护人指导下使用。

七、政策更新

如本政策发生变更，我们会在应用新版本发布时同步更新本页面。
