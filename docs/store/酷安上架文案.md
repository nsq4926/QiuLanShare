# 酷安上架文案（Android 1.0.0）

> 直接复制到酷安开发者中心对应输入框。口径与 `docs/13-功能清单.md` 一致，只写已实现的行为。

## 一、一句话简介（≤30 字）

```
不联网、不注册、无广告的局域网文件与消息互传
```

备选：

```
同一个 Wi-Fi 下，手机、平板、电脑之间直接传文件
```

## 二、详细描述

```
秋秋快传是一款纯局域网的点对点传输工具：不注册、不登录、没有云端服务器，文字、图片和文件只在你的设备与同一 Wi-Fi 下的另一台设备之间直接传输。

【为什么不走服务器】
所有内容都不经过任何中转：没有账号体系，没有广告，没有统计 SDK，应用内也没有任何第三方 SDK。断开 Wi-Fi 它什么也做不了——这是设计，不是缺陷。

【能做什么】
· 自动发现：同一 Wi-Fi 下的设备自动出现，也可以手动填 IP 添加
· 文字、图片、文件双向发送，支持多选
· 单文件最大 4 GB，1 MB 分片 + 断点续传，传到一半断了能接着传
· 实时进度：通知栏显示总大小、速度与百分比
· 全屏看图：双指缩放、双击放大、左右翻页、保存到相册
· 系统分享：从相册/文件管理里「分享」直接发到秋秋快传；也能把收到的文件分享给别的应用
· 深色模式、聊天记录保留期限（不清理 / 7 天 / 30 天 / 90 天 / 退出时清理）
· 后台前台服务保活，切出去也不会中断大文件

【跨端】
Windows 端（TrafficMonitor 插件）、鸿蒙端与安卓端使用同一套协议，三端可以互传。

【隐私】
不收集姓名、手机号、位置、通讯录、剪贴板、设备标识，也不读取应用列表。只申请网络、网络状态、前台服务与通知权限；图片/文件保存走系统保存框。
隐私政策：https://docs.qq.com/doc/DVmdrQUVCck56UEJ0

【适合谁】
经常在手机和电脑之间倒腾照片、安装包、文档，又不想先上传网盘再下载的人。
```

## 四、审核备注（粘到「审核说明 / 备注」）

```
本应用是纯局域网的点对点传输工具，没有账号、没有云端服务器，需要两台设备接入同一个 Wi-Fi 才能看到完整功能。

自测方式（二选一）：
A. 两台设备：设备 A 安装本应用，设备 B 安装同一版本的安卓端（或运行 Windows 端），两端连同一 Wi-Fi，打开后会自动发现对方；不出现时可在「设备列表 → 手动添加」填对方 IP 与端口 8765。
B. 单台设备：打开「设置 → 关于与隐私 → 没有第二台设备？」，页面会显示本机地址与自测三步。

权限说明：仅使用网络、网络状态、前台服务与通知权限，全部用于局域网收发与后台传输；不采集任何个人信息，不申请位置、通讯录、相机、麦克风。
隐私政策：https://docs.qq.com/doc/DVmdrQUVCck56UEJ0
备案号：（如有，填这里）
```

## 六、截图脚本（安卓真机，1080×1920 竖屏）

| # | 画面 | 要点 |
|---|---|---|
| 1 | 设备列表（两台设备在线） | 让「被发现/主动发现」都开着，标题栏显示本机 IP |
| 2 | 会话页文字消息 | 收发各一条，气泡左右分明 |
| 3 | 传文件中（进度抽屉展开） | 选一个 100 MB 以上的文件，露出速度与百分比 |
| 4 | 全屏看图 | 图片页显示页码 `2 / 3` |
