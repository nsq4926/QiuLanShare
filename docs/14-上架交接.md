## 七、已知坑（别重复踩）
- 构建产物会"陈旧"：构建前先删 *.hap / app-debug.apk，再用 mtime 核对
- 鸿蒙主线程同步 >6 s = THREAD_BLOCK_6S 被杀：大文件必须分片 + await 让出
- ArkUI 里 Image.draggable + PanGesture 同挂 = jscrash
- 鸿蒙角标只能 setBadgeNumber 写，撤通知不清
- 安卓多点触摸无法用 adb 注入（双击也不稳），只能靠代码结构保证
- `uinput -K -t` 只吃 ASCII，中文报 "The character of index 0 is invalid"；
  中文要用 `uitest uiInput text '<文本>'`（走输入法注入）
- 逐字删除只能删光标左侧：清输入框要先点**右端**再连按 KEYCODE_DEL(2055)，否则残留会和下一轮输入拼接
- 聊天页按 Back 是**退出应用**，不是回列表；回列表要点左上角那个按钮
- 看图页在**最后一张**向左滑 = 关闭看图；要翻页就从最后一张向右滑
- 开「图片自动存图库 / 文件自动保存」时每收一张都会弹一次系统确认框，录视频前先关掉
- docs/test_*.bin 有 5.1 GB 测试文件（已 gitignore，可删）
