# 17 · 安卓上架（酷安）

> 用途：安卓版发版与上架的操作手册。鸿蒙/AGC 那套看 `14`，本文只管安卓。
> 最后更新：2026-11-22（签名落地、隐私同意页、关于页、R8 上架包跑通）。

## 一、一句话

上架包 = `assembleRelease`（R8 + 正式签名，约 1.4 MB）；上架前必须满足三件事：
**隐私政策可点开、同意前不启动服务、版本号与包名能对上**。三件都已落地，剩下的是商店侧材料。

## 二、签名（2026-11-22 新建，一次定终身）

| 项 | 值 |
|---|---|
| keystore | `android/keystore/qiuqi-release.jks`（PKCS12，**不入库**） |
| 口令文件 | `android/keystore.properties`（**不入库**，`storeFile/storePassword/keyAlias/keyPassword`） |
| alias | `qiuqi` |
| 算法 / 位数 | RSA 2048 / SHA384withRSA 自签 |
| 有效期 | 2026-11-22 ~ 2054-04-09（10000 天） |
| 证书 MD5 | `a9:82:88:e3:ae:b4:b4:32:f1:97:10:5d:61:18:58:f1`（**App 备案要填这个**） |
| 证书 SHA-1 | `6E:85:B2:76:A8:54:0E:35:7C:4B:5D:07:68:5E:7A:5D:7C:61:96:9A` |
| 证书 SHA-256 | `ae041bb12ea350a4624d59b0abe4dc8819b8547065d108a89efbf095ab67ab91` |
| DN | `CN=QiuLanShare, OU=Mobile, O=QiuLanShare, L=Beijing, ST=Beijing, C=CN` |

**铁律**：签名一旦对外发过包就不能换（换了等于新应用：商店更新失败、备案信息作废）。
备份 `qiuqi-release.jks` + `keystore.properties` 到密码管理器/离线介质；丢了只能换包名重新上架。

## 三、构建

```bash
cd android
export JAVA_HOME="D:/APP/AndroidToolchain/jdk-21.0.13+9"
export GRADLE_USER_HOME="D:/DeepSeekWork/LanShare/.work/gh"   # 沙箱里不能写 ~/.gradle
"/d/APP/AndroidToolchain/gradle-8.13/bin/gradle.bat" assembleRelease --console=plain
# 产物：app/build/outputs/apk/release/app-release.apk
```

- 首次/改依赖时去掉 `--offline`（lint 的 `lint-gradle` 不在缓存里会报 `No cached version`）。
- 校验签名：`apksigner verify --print-certs app-release.apk`，要看到 v1 + v2 均为 true。
- 校验版本：`aapt2 dump badging app-release.apk | grep package:` → `versionCode='10000' versionName='1.0.0'`。
- 产物归档：`android/dist/qiuqi-kuai-chuan-1.0.0.apk`（约 1.4 MB，`android/dist/` 已 gitignore）。

**`isShrinkResources` 保持开启**（1.45 MB）。曾怀疑它把 API<26 的传统 mipmap 图标裁掉，
2026-11-22 实测：开关两种都保留 48/72/96/144/192 五档 PNG，**不是资源收缩的问题**。

**版本号规则**：`1.0.0 → 10000`，之后每发一版 `versionCode +1`（`1.0.1 → 10001`）。
酷安与各商店都按 versionCode 判断"是不是更新"。

## 四、合规三件套（代码侧，已完成）

| 项 | 位置 | 行为 |
|---|---|---|
| 首次启动同意 | `ui/PrivacyConsentScreen.kt` + `MainActivity` | 未同意时**不启动 NodeService**（不监听 8765、不广播）、不申请通知权限；同意后才起服务；拒绝则 `finishAffinity()` 退出 |
| 同意状态存储 | `core/Settings.kt` → `privacyAcceptedAt`（毫秒，0 = 未同意） | 老配置没有该键 = 0，升级用户也会看到一次同意页 |
| 应用内隐私入口 | `ui/AboutScreen.kt`（设置 → 关于与隐私） | 版本号/包名/设备标识、隐私政策链接、权限清单、单机自测三步、反馈渠道 |
| 隐私政策托管 | `core/AppLinks.kt` → `PRIVACY_URL` | 腾讯文档，**所有人可查看**（不是"所有人可编辑"） |

## 五、权限清单（与 AndroidManifest 逐条对应）

| 权限 | 用途（对审核的口径） |
|---|---|
| `INTERNET` | 局域网内 HTTP 收发消息与文件（8765 起） |
| `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | 取本机局域网 IP、判断 Wi-Fi 可用 |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_DATA_SYNC` | 后台继续传输大文件 |
| `POST_NOTIFICATIONS` | 新消息与传输进度提醒（运行时申请，可拒绝） |
| `WRITE_EXTERNAL_STORAGE`（`maxSdkVersion=28`） | 仅 Android 9 及以下把用户主动保存的图片/文件写入相册/下载 |

**已移除** `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`：改为「设置 → 后台保活」跳系统电池优化页手动放行。
`usesCleartextTraffic` 保留（局域网无证书），已加 `res/xml/network_security_config.xml` 写明理由。

## 六、酷安上架步骤

> 2026-11-24 反馈：酷安当前没有面向个人的上架入口，改投**应用宝**，见 `docs/18-应用宝上架.md`。
> 下面保留作参考（若渠道恢复或有企业开发者账号）。

1. **注册/登录** [酷安开发者中心](https://developer.coolapk.com/) → 开发者认证（个人：身份证 + 人脸）。
2. **新建应用**：填应用名「秋秋快传」、包名 `com.sanqiu.lanshare`、分类「实用工具 / 传输」。
   - 若提示包名已被收录（有人自行传过），走「应用认领」，别新建（否则评论和历史版本归别人）。
3. **上传 APK**：只收 APK（不收 AAB），上传 `app-release.apk`。
4. **填素材**：图标 512×512 直角 PNG、截图 3–5 张、一句话简介、详细描述、更新日志、隐私政策 URL。
5. **提交审核**：1–3 个工作日；审核备注写清「需两台设备同 Wi-Fi」（见 `store/酷安上架文案.md`）。
6. 通过后：发一条开发者动态（配 GIF + 截图），带话题；盯评论区与闪退反馈。

## 七、App 备案（工信部）

- 依据：工信部信管〔2023〕105 号，未备案不得从事 APP 互联网信息服务。
- **实测证据（2026-11-22）**：华为 MatePad 用 adb 安装未备案包时，安装器直接弹
  「应用备案状态未知 —— 未查询到此应用的 ICP 备案信息」，必须勾选风险确认才能继续装。
  商店上架同样会校验。
- 纯局域网工具可以主张"不提供互联网信息服务"，但**商店后台通常有必填字段**，以实际表单为准；
  需要备案时用上面的证书 MD5、包名、公钥去接入商（阿里云/腾讯云）提交。
- 备案主体、App 名称、包名、签名必须与上架包一致；换签名要重新备案。

## 九、已知坑（安卓侧，长期有效）

- **OPPO/ColorOS 的 `adb install` 会被厂商安装器接管**：跳到 `com.oppo.usercenter` 要求登录 OPPO 账号，
  命令行表现为 `Failure [-99]` 或一直 `- waiting for device -`。本轮实测的绕法：先
  `settings put global verifier_verify_adb_installs 0` + `package_verifier_enable 0`，再重试一次
  `adb install -r` 就 `Success`（第二次安装时用户中心不再拦截）。
- **重装后 OPPO 桌面图标可能还是系统默认机器人**：ColorOS 3 的图标缓存按包名持久化，
  卸载重装/覆盖安装都不刷新；`pm clear com.oppo.launcher` 被系统拒绝（`adb clearing user data is forbidden`）。
  **重启手机**后恢复正常（实测：APK 内 48px 图标是蓝底白箭头，重启后桌面显示正确）。
  别据此误判成"图标被打包器裁掉"——先用 `aapt2`/解包确认 APK 里的 PNG 再下结论。
- **华为「纯净模式」**：adb 安装会弹「风险提示 → 继续安装」，未备案包还会多一层「应用备案状态未知」勾选。
  自动化测试时要先点掉（`android_tap_element` 找「继续安装」/勾选框）。
- **腾讯文档默认可能是「所有人可编辑」**：隐私政策必须改成「所有人可查看」，否则任何人能改你的政策。
- **R8 打开后要复跑冒烟**：`isMinifyEnabled=true` 且 `proguard-rules.pro` 之前根本不存在（本轮补上）。
  出现 `ClassNotFoundException` / 字段变 null 再补 keep 规则，别一上来就 `-keep class ** { *; }`（等于没混淆）。
- **`assembleRelease` 离线会挂在 `lintVitalRelease`**：它要下 `com.android.tools.lint:lint-gradle`；
  离线跑就加 `-x lintVitalRelease`，正常发版联网跑一次 lint。
